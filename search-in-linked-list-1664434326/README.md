# [Search in Linked List](https://www.geeksforgeeks.org/problems/search-in-linked-list-1664434326/1)

**Difficulty:** Easy

Given a linked list with the head node and a key, the task is to check if the key is present in the linked list or not.

**Example:**

```
Input: key = 3,      Output: true Explanation: 3 is present in Linked List.
```

```
Input: key = 4,   Output: falseExplanation: 4 is not present in Linked List.
```
