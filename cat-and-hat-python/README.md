# [Cat and Hat](https://www.geeksforgeeks.org/problems/cat-and-hat-python/1)

**Difficulty:** Medium

You are given a string**s**, you need to return **True**if  the words "cat" and "hat" appear same****number of times****in **s**, otherwise return **False**.

**Note:** s contains only lowercase English alphabets.

**Examples:**

```
Input: s = "catinahat"
Output: True
Explanation: cat and hat both are present 1 number of times.
```

```
Input: s = "bazingaa"
Output: True
Explanation: cat and hat both are present 0 number of times.
```

**Constraints:**

- `1 ≤ s.size() ≤ 10^5`
